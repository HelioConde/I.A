# Jogo experimental escrito pelo Ornith 1.5 9B

**Autoria do arquivo `game.js`: Ornith 1.5 9B, inferência GGUF local**.
A versão inicial foi gerada no run [40653494692](https://github.com/HelioConde/I.A/actions/runs/40653494692).
Duas correções de `player.vy` e `KeyboardEvent.code` foram geradas pelo **mesmo modelo** no
[run 40660720374](https://github.com/HelioConde/I.A/actions/runs/40660720374).
O arquivo `provenance.json` contém respostas, SHA-256, tentativas e autoria.

O arquivo `index.html` é um **harness de teste escrito pelo ChatGPT**, não pelo Ornith.
Esse é um **minijogo de benchmark**, não o jogo completo Luna Arcade S1. O Chromium
passou em **4/4 testes** (movimentação, pulo, dano a inimigos, responsive mobile);
não representa aprovação de qualidade artística ou de um jogo longo.

Este branch **não publica nem substitui** `/I.A/luna-created/`.
